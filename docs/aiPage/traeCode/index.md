# TraeCode 使用流程与能力优势

> TraeCode 是一款深度融合 AI 能力的开发工具，提供从代码编写、项目理解、调试运行到变更管理的完整开发体验。你可以像使用传统 IDE 一样掌控每一步，也可以把复杂任务交给 AI 智能体规划和执行。

---

## 一、TraeCode 是什么

TraeCode 是 TRAE 旗下的 AI IDE 产品，以智能生产力为核心，无缝融入开发流程。它覆盖从编码、调试到测试、重构、部署等多类开发任务，支持代码续写、文档生成、逻辑审查与结构优化等，适配多种日常开发场景，帮助开发者减少重复操作，专注核心创新。

---

## 二、安装与初始设置

### 1. 安装

前往 [TRAE 官网](https://www.trae.com.cn/)，点击右上角的 **下载 IDE** 按钮，将安装包下载到本地并完成安装。

支持的操作系统：

| **操作系统** | **最低版本 / 发行版** | **架构** |
|---|---|---|
| macOS | 12.0 及以上 | Apple Silicon、Intel |
| Windows | Windows 10、Windows 11 | 64 位（x64） |
| Linux | Ubuntu 20.04+、Debian 10+、Fedora 42、RHEL 9.x | x64、ARM64 |

### 2. 初始设置

启动 TraeCode 后，跟随界面指引完成：

- 选择主题和语言
- 从 VS Code 或 Cursor 导入已有配置
- 添加 TraeCode 相关的命令行
- 使用手机号、抖音、苹果或稀土掘金账号登录

### 3. 配置开发环境

前往 **设置 > 开发环境**，配置本地开发运行环境。当前支持配置 Node.js 版本，用于指定 TraeCode 在运行项目、安装依赖、执行构建或测试命令时使用的 Node.js 环境。

## 三、打开项目

你可以通过以下三种方式打开项目：

### 方式一：导入本地文件夹

1. 点击左侧面板的 **打开文件夹** 按钮
2. 从本地选择一个文件夹并打开

### 方式二：从 GitHub 克隆仓库

1. 点击 **克隆 Git 仓库** 按钮
2. 在弹出的面板中点击 **从 GitHub 克隆**
3. 完成 TraeCode 与 GitHub 间的授权，将目标仓库克隆至本地

### 方式三：从 URL 克隆仓库

1. 点击 **克隆 Git 仓库** 按钮
2. 输入目标 Git 仓库的 URL
3. 将目标仓库克隆至本地并打开

## 四、使用流程

### 步骤 1：选择开发模式

TraeCode 提供双重开发模式，可在界面左上角自由切换：

- **IDE 模式**：保留传统的开发方式，开发者全程自主控制流程，适合需要精细控制代码改动和执行过程的场景。
- **SOLO 模式**：以 AI 为主导，自动规划任务并完成从需求理解、代码生成、测试到成果预览的全流程。

### 步骤 2：与智能体协作

进入 SOLO 模式后，点击 AI 对话输入框左下角的 **@** 符号，选择 **SOLO Agent**。

SOLO Agent 是一个面向复杂项目开发的智能体，能够助力你高效完成从需求迭代到架构重构的全流程开发工作。

### 步骤 3：选择执行模式

在对话输入框中输入 `/`，可选择不同的执行模式：

#### Plan 模式

适用于中小型功能开发和模块级重构。SOLO Agent 收到需求后，会分析需求并规划任务，生成一份规划文档，待你确认后一一执行。若计划不符合预期，可直接手动编辑或发送修改需求。

#### Spec 模式

面向更复杂的系统级任务。SOLO Agent 会生成完整的三阶段文档组：

- `spec.md` — 需求大纲
- `tasks.md` — 任务列表
- `checklist.md` — 验收清单

文档存储在项目根目录的 `.trae/specs/` 目录中，可作为项目知识资产长期保留。确认执行后，任务列表和验收清单的状态会随着执行进度自动更新。

适用场景：从零搭建新系统、大规模重构、多人协作项目、核心业务功能开发、需长期维护的项目。

### 步骤 4：输入需求并查看变更

通过自然语言描述、语音交互或上传本地文件等方式输入需求，AI 会自主拆解任务并高效执行。

变更完成后，点击对话面板中的 **查看变更** 或 **代码变更** 按钮，可查看本次项目变更涉及的文件数量、变更的代码行数，以及变更的文件列表，以 diff 视图的方式展示。

## 五、核心能力与优势

### 1. 双重开发模式

| 模式 | 特点 | 适用场景 |
|---|---|---|
| IDE 模式 | 保留熟悉的编辑器、终端、调试、插件、源代码管理等工作流，掌控感更强 | 需要精细控制代码改动的日常开发 |
| SOLO 模式 | AI 主导任务，自动推进开发任务，从自然语言输入到可执行产出 | 从 0 到 1 创建项目、复杂功能开发、架构重构 |

### 2. AI Coding Agent

- 可理解目标、规划任务并调度工具，独立推进各阶段开发工作
- 支持自动拆分复杂任务，带来流畅交付体验
- 可自主编排多个智能体，组建属于你的 AI 团队，实现多角色协同工作

### 3. 开放的智能体生态

- 可自由配置智能体的提示词、MCP Server 和工具集
- 支持创建自定义智能体并分享到市场，像插件一样灵活组合
- 提供多种一键导入的智能体模板（UI 设计师、代码审查等）

### 4. MCP 工具自由装配

通过 MCP（Model Context Protocol），可以赋予智能体专属的外部资源调用能力，让智能体根据个人需求灵活调用工具，打造独一无二的任务执行能力。

### 5. 超强上下文理解

- 不仅理解代码仓库、终端信息等 IDE 内信息
- 支持联网搜索、上传文档集作为上下文
- 可配置 TRAE Rules，让 AI 按照你的工作规则执行定制化任务

### 6. CUE 智能编程助手

- 代码补全、链式补全、多行修改
- 修改点预测与跳转（点击 Tab 快速应用建议）
- 智能导入和智能重命名
- 提供直观 diff 对比

### 7. 完整的开发工具链

- **代码编辑与调试**：支持主流编程语言和开发框架
- **源代码管理**：内置完整的 Git 工作流，AI 可生成规范的 Commit Message
- **智能代码审查**：对未提交变更、单次提交或分支差异进行总结和审查
- **插件扩展**：支持丰富的插件生态
- **远程开发**：支持通过 Remote SSH 或 WSL 连接远程主机

### 8. Figma 设计还原

AI 可自动解析 Figma 设计文件，将设计元素转化为可运行的代码。既可选择整个 Frame 生成完整页面，也可精准选择单个组件生成代码片段。

### 9. 隐私与安全

- **隐私模式**：开启后不会将对话内容、代码片段及 AI 输出用于数据分析或模型训练，代码库文件始终保存在本地
- **沙箱运行**：智能体生成的命令在受限环境中执行，通过文件访问控制和高风险命令拦截降低误操作风险
- **区域化部署**：用户数据与服务依据账号归属地存储，满足当地数据法规合规要求

---

## 六、典型使用场景

- **从 0 到 1 创建项目**：自然语言描述需求 → 智能体拆解任务 → 代码生成 → 运行验证 → 结果预览
- **维护已有代码库**：基于项目上下文定位文件 → 理解依赖关系 → 修改、重构或排查问题
- **提升编码效率**：CUE 代码补全 → 多行修改 → 修改点预测 → 智能导入与重命名
