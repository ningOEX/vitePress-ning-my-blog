# SVG


## 1. SVG 标签属性
> viewBox 属性允许指定一个给定的一组图形伸展以适应特定的容器元素。 [详细参考](https://developer.mozilla.org/zh-CN/docs/Web/SVG/Reference/Attribute/viewBox)
> preserveAspectRatio 属性表示是否强制进行统一缩放。  [详细参考](https://developer.mozilla.org/zh-CN/docs/Web/SVG/Reference/Attribute/preserveAspectRatio)


## 2. 线性渐变

> linearGradient 元素用来定义线性渐变，用于图形元素的填充或描边。[详细参考](https://developer.mozilla.org/zh-CN/docs/Web/SVG/Reference/Element/linearGradient)

## 3. 径向渐变

> radialGradient 用来定义径向渐变，以对图形元素进行填充或描边。[详细参考](https://developer.mozilla.org/zh-CN/docs/Web/SVG/Reference/Element/radialGradient)
